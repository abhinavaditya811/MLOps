I successfully set up a complete MLOps data versioning pipeline from scratch. First, I installed DVC with Google Cloud support using pip install "dvc[gs]", making sure to use quotes to prevent a Zsh-specific error. I then initialized the project with both git init and dvc init, establishing the core concept that DVC works with Git, not in place of it. The main task was configuring the Google Cloud remote: I used dvc remote add to create it, dvc remote default to set it for convenience, and, most importantly, dvc remote modify --local credentialpath ... with the full absolute path to my JSON key. This step was crucial as it fixed the 401 Invalid Credentials error, while the --local flag kept my secret key file secure and out of the Git history.

Once the configuration was solid, I executed the core DVC workflow. I used dvc add data/CC_GENERAL.csv to tell DVC to track my large dataset, which in turn created the small data/CC_GENERAL.csv.dvc pointer file. After fixing a small typo in the filename (.csv.dvc instead of _csv.dvc), I added this pointer file to Git with git add and saved this data version with git commit. Finally, I ran dvc push to upload the actual large data file to my Google Cloud Storage bucket and git push to save my code and data pointers to GitHub.
